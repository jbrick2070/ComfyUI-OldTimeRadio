## 1. Problem description (unchanged)
The character dialogue generated by the IndexTTS2 TTS model has an unintended "whiny" / pleading quality. The announcer voice (Kokoro) is fine in the mix; the primary character voices (Hayes, Gulliver) lack vocal weight and sound perpetually complaining. Era accuracy is NOT the issue -- modern-sounding delivery is acceptable.

## 2. Grounded reality check (verified against the repo + live bank, 2026-06-10)
- **G1 -- The bank is 37 indextts2 char refs, not 4** (14 male + 22 female + narration; cb_*/dia_* mirrors). Female additions NOT needed.
- **G2 -- All 36 ref WAVs exist on disk**; the missing-ref bark fallback SHOULD not fire -- but its WARNING goes only to the node's render_log STRING, and `otr_runtime.log` carries ZERO voice-render lines. **Per-line engine identity is persisted nowhere; bark on past episodes cannot be excluded retroactively** (H4).
- **G3 -- Bank metadata is machine-stamped, never human-audited.** Gender by median-F0 threshold (165 Hz); generic timbre tags; `vz_donor_james` / `vz_donor_hillbilly_jim` in the FEMALE pool are probable threshold artifacts.
- **G4 -- Casting is a uniform per-episode lottery.** Canonical graph: node 81 indextts2, node 82 kokoro, node 80 CastLock auto_registry `allow_voice_reuse=true`. In-tier pick is `random.Random(seed).choice(pool)` -- uniform; scores only sort. Writer timbre vocab does not match bank tags, so male characters draw uniformly across all 14 male refs per episode_seed.
- **G5 -- scene_tension is never stamped** -> the delivery vector is keywords + punctuation only.
- **G6 -- The derived vector is biased toward whiny-adjacent emotions** (interrogatives -> surprised; help/run/danger -> afraid; sorry/lost/gone/alone -> sad; remember/once/ago -> melancholic); "?" adds 0.5 raw; 3 cues saturate a dim; NO total-mass cap; calm collapses fast; keyword+punctuation double-dips.
- **G7 -- emo_alpha pinned at 1.0** adapter-side; the worker already accepts a per-request value.
- **G8 -- True-neutral A/B free:** `OTR_DELIVERY_VECTOR=0` -> all-zero -> worker OMITS emo_vector. A default-path "neutral" line still sends calm=1.0 @ alpha 1.0 -- a different render; IndexTTS2 calm semantics UNVERIFIED.
- **G9 -- Observability gap:** resolved voice_ref_id per character is not logged or persisted on the default path; CastLock's report STRING is not persisted either.
- **G10 -- Versioning hooks exist** (DELIVERY_TABLE_VERSION; voice_bank_id+sha; PREPARE_TEXT_VERSION; profiles dormant).
- **G11 -- Same-voice collision possible** on the render-time path (allow_voice_reuse=True, no episode used-set); CastLock auto_registry HAS a used-set that the widget `allow_voice_reuse=true` defeats.
- **G12 -- The adapter skips full text normalization** (`clean_spoken_text` only): `?` `!` `...` em-dashes/colons/caps ride into the engine -- an independent punctuation-prosody channel.
- **G13 -- The delivery vector is derived from RAW pre-strip text** (runs before prep); parentheticals cue emotions then vanish from the spoken text.
- **G14 -- Ref preprocessing is peak-normalized (0.97), never loudness-normalized; no clipping/SNR screen; refs are 44100 Hz vs engine 22050** (internal resample behavior UNVERIFIED).
- **G15 -- Solo-vs-mix unsplit:** dense/compressed Kokoro vs dynamic IndexTTS2 output; nothing measures character clips against the announcer or the bed.
- **G16 -- Reuse/tier constraints verified:** CastLock catches `VoiceCastingError` per char ("NOT cast" -> render-time resolution takes over); `assign_voice_for_slot` has no tier concept (tier logic must pre-filter the pool); the render-time fallback uses the FULL bank with reuse=True, so it can bypass any CastLock-side uniqueness or tier policy.
- **G17 -- (pass 2, verified) Per-line prosody seed instability.** `engine_seed = _seed_to_int64(engine, request.stable_line_seed)` -- every line of the SAME character samples a fresh prosody draw. A character can be hesitant on one line, bright the next; zero-shot models can read this as nervous/pleading. No per-character seed mode exists.
- **G18 -- (pass 2, MEASURED on the live bank) Ref loudness + trimmer evidence.** Measured all 36 WAVs: donors sit at RMS 0.089-0.187 with 0.97 peaks; **the four curated voice-zero refs are loudness outliers** -- `stuart_bell` RMS 0.027 (peak 0.22), `peter_yearsley` 0.035 (0.31), `bill_boerst` 0.052 (0.37), `caro_davy` 0.061 (0.40) -- never normalized, 2-6x quieter than every donor. A zero-shot cloner that copies vocal effort gets a soft, low-projection prompt from exactly the "premium" male refs. Also: durations are flat 10.00s (donors) / 12.00s (narration = the first-12s fallback branch) / 5.9-10.8s (originals) -- **no ref is under 5s**, which REFUTES the pass-2 claim that the trimmer shipped single-vowel clips, while CONFIRMING the trimmer logic itself is latent-broken (the longest-voiced-run breaks at every unvoiced frame; the <2s fallback to "first 12s raw" is what actually shipped). Fix the trimmer before any future re-download; the current bank never went through a working trim.

## 3. Root-cause hypotheses (v3 -- five channels, all mechanism-grounded)
- **H1 Ref pool (timbre + read style + EFFORT):** thin/noisy/politely-read donor refs in a uniform lottery, PLUS the measured low-RMS originals (G18) -- a quiet, low-effort prompt can clone as weak/pleading regardless of pitch. F0 alone cannot rank any of this.
- **H2 Delivery (vector + alpha):** keyword-saturated afraid/sad/surprised vectors at alpha 1.0.
- **H2b Punctuation prosody:** `?`-heavy text reaches the engine un-normalized (G12) and shapes contours independently of the vector.
- **H2c Mix perception:** character clips may sit quieter/thinner than Kokoro against the bed (G15).
- **H2d Prosody-draw instability (NEW, pass 2):** per-line seeds (G17) make a character's stance wander line to line -- "whiny" may partly be "unsteady".
- **H3 Compounding:** worst case = quiet thin ref + saturated vector + rising "?" + fresh draw per line + under-weighted clip in the mix.
- **H4 Past episodes may literally be bark** (operator-ear evidence; unprovable retroactively until P3a; P0-zero proves fresh renders).
- Ruled out: era/vintage framing; announcer path; engine-widget misconfiguration; "the bank is vowel-moan clips" (G18 measurement).

## 5. Hardened plan v3 (no architectural overhaul; all changes additive + versioned)
**P-OBS -- Minimal observability FIRST (coder, ~1 h, CPU-only, no audio-byte change).** Render_log gains per-character (and per-fallback-line) lines: `char_id -> voice_ref_id -> ref_path basename -> engine -> alpha -> delivery_version -> vector(omitted|zero|nonzero) -> seed`, plus a clip-sample-rate==pack-sr assert. Mirrored to the runtime log. This unblocks attribution for EVERY subsequent step (pass-2 convergent finding); the durable-ledger restamp stays in P3a but no longer gates diagnosis.
**P0-zero -- PROVE which engine rendered (operator, ~10 min, zero code).** Queue one 30-word smoke; read node 81 render_log + node 80 CastLock report from `/history/<prompt_id>`: `rendering N lines on 'indextts2'` vs bark WARNING. Bark present -> fix ref resolution first. Fresh-renders-only limitation stays explicit.
**P0a -- Solo-vs-mix split on EXISTING audio (operator, ~15 min, zero render).** Take known-whiny character lines from an existing episode: listen solo loudness-matched, then in the mix. Solo-OK/mix-thin tilts the whole effort toward H2c before any TTS tuning (pass-2: do this EARLY, not as a final gate). Free offline test on one bad WAV ("0/30/70/100% fixed?"), first recipe (pass-3 concrete): proximity-EQ low shelf +3 to +6 dB below ~200 Hz with a gentle -2 dB wide cut near 500 Hz, light 2:1 compression, loudness-match to the announcer, optional -2 dB bed duck under the line.
**P0 -- Audition matrix (operator GPU, ~1 h scripted, zero pipeline code).** Drive the Path-B worker directly with hand JSON. **Preflight (pass-3): one-hot emotion-axis sanity** -- render one neutral line 8x, each dim alone at 1.0, same ref/seed: verify each dimension sounds like its label (the EMOTIONS order is an ASSUMED contract; if calm/surprised misbehave, all vector tuning re-anchors). Lines: 3 synthetic (neutral declarative / question-heavy / fear-urgent) + **2-3 REAL offending lines from the episode** + 1 one-word interjection vs 1 long line (length cell). 3 seeds each, loudness-matched playback, spectral report (median F0, final-500ms rise, centroid, RMS, low-mid ratio) auto-computed on every output, PLUS the 10-line correlation check: terminal-? count vs final-rise across all outputs (r > 0.6 -> the punctuation lever is the dominant cheap fix). Triage order to limit listening fatigue: vector-off bad/good ref -> current vector -> alpha 0.45 -> punctuation variants on real lines -> seed panel; expand to calm/angry/resample cells only if those six leave the whine unexplained. Conditions:
  1. `vz_bill_boerst`, vector OMITTED (quiet-original baseline)
  1b. best-PROJECTION donor ref, vector OMITTED (loud-donor baseline -- pick by composite: normal LUFS, low clipping, strong voiced chest band, low final-rise; NOT raw RMS, which can be compression/noise -- G18 says these two baselines may differ by themselves)
  2. derived v1 vector @ alpha 1.0 (reproduce today)
  3. punctuation variants, vector OMITTED: terminal `?` -> `.` vs `?!` vs `...` vs ALL terminal punctuation stripped (the strip cell isolates the engine's `?`-token bias completely; H2b direction is unknown -- Gemini warns `.` may read depressed)
  4. worst-suspect ref (P2a composite rank), vector OMITTED; and @ alpha 0.65 (H1 + interaction)
  5. alpha sweep 0.25 / 0.45 / 0.65 on the v1 vector
  6. calm=1.0 only; and angry-floor 0.15 only (vector-shape cells)
  7. one ref pre-resampled to 22050 mono, vector OMITTED (G14)
  8. **fixed-character-seed panel:** 6 consecutive lines, per-line seeds vs one fixed seed vs char-base+occurrence-offset (H2d). Interpretation caveats (pass-3): a fixed seed can force the SAME cadence onto different-length lines (robotic sameness), and a "fixed wins" verdict can be RNG-path luck rather than steadier prosody -- listen for both before choosing; if a mode wins -> `OTR_INDEXTTS2_SEED_MODE` versioned option, default `line`
  9. neutral-rewrite of one whiny line, same ref/seed (whine-from-WRITING split -- measures the script's contribution without reopening the writer)
  Decision gate: per-channel verdicts H1/H2/H2b/H2d + alpha default + calm policy + cap strategy + punctuation variant (or none) + seed mode (or none).
