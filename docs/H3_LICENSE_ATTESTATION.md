## 3. Operating constraints this build honors

Adopted as the working standard despite the recorded 2b ambiguity --
deliberately the NARROW reading, so the build cannot exceed whatever was
actually promised:

- H3 inference runs only on the operator's own hardware, offline. No hosted
  service, no shared or public inference endpoint.
- H3 weights are never redistributed, republished, mirrored, or bundled into
  any release artifact of this project -- in any form, quantized included.
- H3 outputs are used within the operator's own productions; no sublicensing
  of the model or its weights.
- Commercial scope: NOT established in writing (see 2b). Treat as
  non-commercial until MiniMax confirms otherwise.
- The underlying MiniMax H3 Community License carries geographic terms that
  this authorization does not restate. The authorization is read as the
  controlling instrument for this operator; if that reading is ever
  challenged, H3 lanes stop until it is settled in writing.
- If any constraint above ceases to hold, H3 lanes are disabled until the
  authorization is re-confirmed.
