# GO_FORWARD — a tech-house set for Suno

Three tracks off the plan. Each has a **Style** line (paste into Suno's style
field) and **Lyrics** (paste into the lyrics field, tags included). Tech house
wants sparse, chanted hooks over the groove — these are written that way, not as
verse-heavy songs. All ~124–127 BPM.
