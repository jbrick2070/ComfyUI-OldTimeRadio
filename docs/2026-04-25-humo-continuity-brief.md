# HuMo Continuity Pipeline — Cowork Brief

**Stack:** RTX 5080 16GB, ComfyUI v0.16.4, HuMo 14B fp8_e4m3fn scaled (Kijai) — promoted to production 2026-04-25 PM, see ROADMAP Hardware Floor; lightx2v 4-step + uni_pc 6-step, 177 frames, 640×640
**Goal:** Multi-clip narrative continuity with stable identity across 4–5 hops

**Ledger schema:** L2 (`l2-2026-04-25`) — adds the beat layer to the hierarchy (Scene > Shot > **Beat** > Clip). A beat is a single-speaker continuous turn within a shot. The orchestrator's daisy-chain only fires within a beat (`boundary == "continue"`); speaker changes inside a shot trigger a `beat_start` clean reset; new shots trigger a `shot_start` full reset.

---

## Architecture (verified)

- Ref image VAE-encoded, **appended at end** of temporal latent sequence
- `mask=1` on anchor position, `mask=0` on generated frames
- Frame 0 is denoised from noise with attention to anchor — **not copied**
- Source: HuMo paper (arXiv 2509.08519), kijai/ComfyUI-WanVideoWrapper inference path

**Implication:** Naive daisy-chain (`next_ref = prev_last_frame`) accumulates drift. Each hop bakes prior motion blur, mid-phoneme mouth, and lighting state into the new identity anchor.

**Caveat:** Trained on 97-frame clips. 177-frame runs are out-of-distribution before chaining is even considered.

## Stage 0 — Disambiguation render (1 clip)

Verify the anchor-vs-seed claim before building anything.

```
ref:    clean FLUX portrait
audio:  any 7s slice
output: extract F1_0, compute SSIM(input_portrait, F1_0)
```

| SSIM(input, F1_0) | Interpretation | Action |
|---|---|---|
| > 0.97 | First-frame seeding | Redesign — naive chain works |
| 0.80–0.93 | End-of-sequence anchor | Proceed to Stage 1 |
| < 0.80 | Weak conditioning | Increase scale_t, recheck VAE |

---

## Stage 1 — Two-clip seam test

```
C1 = humo(ref=clean_portrait,  audio=A1) → save F1_176
C2 = humo(ref=F1_176,           audio=A2) → save F2_0

metrics:
  seam_ssim   = ssim(F1_176, F2_0)
  id_cosine   = arcface(F1_0, F2_0)
```

**Gate:** `seam_ssim ≥ 0.95 AND id_cosine ≥ 0.85` → skip to Stage 4
**Else:** Stage 2

---

## Stage 2 — Hybrid anchor (ComfyUI native)

No custom node. Insert `Image Blend` before VAE Encode.

```
ref_image = α × clean_portrait + (1−α) × prev_last_frame
```

**Sweep:** α ∈ {0.5, 0.7, 0.9} on a 2-clip seam test
**Pick:** highest seam_ssim where id_cosine ≥ 0.85

---

## Stage 3 — 5-hop validation

```python
metrics = []
prev_last = None
for i in range(5):
    ref = blend(clean_portrait, prev_last, alpha) if prev_last else clean_portrait
    clip = humo(ref, audio[i])
    metrics.append({
        "hop": i,
        "seam_ssim":   ssim(prev_last, clip[0]) if prev_last else None,
        "id_vs_clean": arcface(clip[0], clean_portrait),
        "id_vs_F1_0":  arcface(clip[0], metrics[0]["F1_0"]) if i > 0 else 1.0,
    })
    prev_last = clip[-1]
```

**Drift trigger:** `id_vs_clean < 0.80` → force clean re-anchor on next clip (α = 1.0)
**Hard reset:** `id_vs_clean < 0.70` → cut point, motivated camera move required
