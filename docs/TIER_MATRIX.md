# The shipping set

Generated by `scripts/otr_tier_matrix.py` from `config/profiles/` for the
ids in `build_variants.SHIPPING_SET`; `--check` fails when this file or the
README block is stale. Local graphs inherit Kokoro voices, MusicGen, and
upscaler off from the canonical. The Comfy Cloud graphs swap those for
ElevenLabs, Sonilo, and partner video/stills. Weights: `auto` fetch themselves at
the first queue, `manual` are listed in the graph's `.launch.md`, `none`
means the lanes need no video weights.
