# Update post for 2.1.3

Paste the block. Notes at the bottom on what to change before it goes out.

---

```
## What changed

**The writer node is a lot less confusing.**

If you have opened OTR_LedgerScriptWriter and felt lost, that was fair. It had
grown to 37 controls in the order they happened to be added over several months,
which is to say no order at all. Three separate reviewers were asked
independently to lay it out the way it should have been, and this is the result.

The node now opens with the control that actually decides what you get:

    Source Bank -> Source Work -> Visual Style -> Title -> Your Idea
    -> the four My Story fields
    -> how long, how many people
    -> how it reads
    -> which model writes it
    -> machine settings you set once
    -> replay

Everything you touch per episode is at the top. Everything you set once for your
hardware is at the bottom. Nothing was renamed, so your saved graphs and any
scripts you have still work.

**Ten dead controls are gone.**

Widgets that did nothing were still sitting there looking like they did
something:

- `perfect_run_spacesaver` — had done nothing since August, when the node it
  drove was retired.
- The `ffmpeg` box on five nodes — it had been ignored for a while already, for
  a good reason: a value typed there could reach the program the pack runs, and
  it arrives over an unauthenticated request. Setting `OTR_FFMPEG` in your
  environment is, and stays, the way to point at a specific build.
- Two seed boxes on the video director — the tooltip said it outright:
  "changing this does not change the picture."
- Two duplicate episode-title boxes. The title lives on the writer now, in one
  place.

If you never touched any of these, nothing about your episodes changes.

**Seven new guides, and they ship with the pack.**

There is now a page for each choice you actually make — the writer models, the
voices, the music, the image models, the video models, the visual styles
(including adding your own), and the upscale step — plus one for the six source
banks, which is the control that decides what kind of episode you get. They live
in `apple/` next to the install and run guides, so a Manager install has them on
disk.

They are written against the live model catalogue rather than from memory, which
turned up three real bugs while they were being written. One of them mattered: a
fresh writer node was offering a model name that did not match any entry in its
own dropdown, which quietly falls through to whichever model happens to sort
first. Fixed, and there is now a check that fails if any node in the pack does
that again.

**AMD.**

A Radeon owner produced the first episode off an AMD card. AMD has shipped
experimental precisely because it had a working graph and no receipts, and that
is now no longer true.

They also gave the most useful piece of feedback the project has had: the audio
and the visuals feel disconnected. That is a fair hit. The two are generated by
stages that agree on the script and not much else. Fixing it properly means an
editing pass over the finished audio and picture together, which is the next
real step rather than a tweak, and it is waiting on local models good enough to
do that inside a ComfyUI workflow. No cloud, no keys — that is the point of this
pack and it is not going to change to buy a shortcut.

**Proof.**

Every one of the 17 shipped graphs was converted and validated against a live
server, and the 16 GB NVIDIA set was rendered end to end — real episodes, not a
green test run.
```

## Before this goes out

* **The AMD line.** Says "a Radeon owner" — swap in their name or handle if they
  are happy to be named, and link their write-up. Ask first.
* **Whether to call AMD v2.1.** `apple/ROCM.md` says the first episode off a card
  is what promotes it. That is your call to make, not a doc's, so the post says
  what happened rather than declaring a status.
* **The proof paragraph is deliberately modest.** As written it claims the
  submit validation across all 17 and the 16 GB NVIDIA renders, which is what is
  actually finished. Do not widen it to "every graph rendered" -- the Mac four,
  the 8 GB four, AMD and CPU were not rendered in this round.
* **"Ten dead controls"** = 1 spacesaver + 5 ffmpeg + 2 director seeds + 2
  duplicate titles. Counted, not estimated.
* It does not mention the version number, so it works as a release note or as a
  standalone post.
