Where the sameness actually is — 3 layers

  • FIXED Premise sameness — the pitch room genuinely diversifies the setup (proven across the soak).
  • FIXED Style sameness — the auto picker mints varied, topic-matched styles.
  • OPEN Composition sameness — the local model collapses any premise+style into the console/kill-switch climax. This is the plateau. Not fixable by more upstream cleverness.

Levers that could break the composition collapse

  • OFF, built L1/L2 noun-grounding (OTR_STORY_QUALITY_L12) — substitutes each GENERIC_CRISIS_NOUN with a premise-specific object. Cheap test; turn it ON.
  • to build Anti-trope composer constraint — ban the crisis-noun vocabulary + the "countdown / self-destruct / blow everything" climax in the beat/line prompt; force the conflict to play in the dialogue.
  • to build Soften the "irreversible_choice" climax — frame it as a private/interpersonal choice (the pitch's final_20_seconds already specifies one; the composer ignores it).
  • real fix Frontier writer — point creative_writing_model at an openrouter: slug. Frontier models don't collapse to the trope; the only lever that moves the grade past ~65.
