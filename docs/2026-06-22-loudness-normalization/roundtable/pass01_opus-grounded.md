# R1 grounded panelist review (Claude) -- per-segment loudness normalization

## Headline recommendation

Ship **RMS-based per-segment loudness** as the default new path, with **LUFS (BS.1770) only if
`pyloudnorm` is already importable** (verify; do not add a heavy dep for the first cut). Gate the new
behavior behind an env knob that **defaults to today's peak behavior**, so `test_audio_byte_identical`
stays GREEN until the operator deliberately flips it and re-baselines. This makes it shippable as a
dark/opt-in chunk instead of a spine-breaking commit.

## Grounded points (checked vs the excerpt)

1. **The seam is `_normalize_clip` (line 93).** It already does the right SHAPE -- scale the whole
   clip by one gain, preserving intra-clip dynamics -- just on the wrong METRIC (peak). The change is
   to compute the gain from a loudness measure, not the peak. Keep the `peak < 1e-6` silence guard and
   add a noise-floor gate just above it.
2. **Determinism is free here (invariant I-11).** RMS is pure numpy on CPU and bit-deterministic.
   `pyloudnorm` is also deterministic but adds a dep + a K-filter; for short radio lines RMS tracks
   perceived level well enough. Decide LUFS-vs-RMS on dep availability, not theory.
3. **Double-gain is the real trap.** `_master_loudness` (line 109) already applies +4 dB makeup
   (`OTR_MASTER_MAKEUP_DB`) + a tanh limiter + a -1 dBFS ceiling at the EPISODE level. If per-segment
   normalization raises the quiet clips, the mix's crest factor changes and the master makeup will
   over-lift. Plan to **retune the master makeup down** (or measure post-segment loudness and set
   makeup from the gap) in the SAME change. Never remove the master ceiling -- it's the peak-safety
   net.
4. **Byte-identical gate.** Any per-segment gain change alters bytes. Rather than a hard
   spine-break, add `OTR_SEGMENT_LOUDNORM = peak (default) | rms | lufs`. Default `peak` = byte-
   identical preserved; flipping to `rms`/`lufs` is the deliberate, operator-gated re-baseline. The
   golden fixture is regenerated by a headless render on the flip.
5. **Scope = dialogue clips only.** Leave the SFX path (line 726, `_normalize_clip` at 0.85) and the
   music beds on their existing path for the first cut; announcer uses the dialogue path. Widening
   scope later is additive.

## Answers to the open questions

1. **LUFS vs RMS:** RMS first (zero-dep, short-clip-stable); LUFS as an opt-in mode IF pyloudnorm is
   on disk (verify import + license). Don't block the fix on a dep.
2. **Target level:** target a NEUTRAL per-segment level relative to today's loudness so the episode
   master makeup barely moves; pick the target by measuring the current mix's mean dialogue loudness,
   not a broadcast number in the abstract. Tie target + master makeup together to avoid double-gain.
3. **Max-gain clamp + noise gate:** clamp gain to ~ +/-(6-9) dB and gate clips whose loudness is
   below a floor (treat as silence/room tone -> no gain). Prevents pumping breaths and hiss.
4. **Short clips:** RMS handles one-word lines fine; if LUFS is used, fall back to RMS/peak below a
   min duration (~0.4 s) where integrated loudness is unstable.
5. **Where:** in `_normalize_clip` (or a sibling `_loudness_gain`) on the dialogue path; one place,
   capability-gated by the env knob.

## Risks the panel should pressure-test

- Pumping / over-amplified breath if the noise gate or max-gain clamp is wrong.
- Double-gain with the master makeup if the two aren't retuned together.
- Re-baseline discipline: the byte-identical golden MUST be regenerated deterministically and the
  diff eyeballed, or a real regression could hide inside the "expected" change.
- Dep creep if LUFS is forced before verifying pyloudnorm is present.
