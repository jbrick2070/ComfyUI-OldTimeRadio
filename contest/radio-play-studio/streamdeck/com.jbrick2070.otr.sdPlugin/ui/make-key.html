Waiting for the Studio…

This key

Press to make the episode from what the dials (or choice keys) show. The ring fills as it is made; when it is done, press to play it. If the run failed, the key says why and a press clears it. Hold the key to open the Studio page on the run the deck is following. While the page is making an episode, the key follows that one.

Studio

Radio Play Studio answers on 127.0.0.1 only. Open the Studio page.
