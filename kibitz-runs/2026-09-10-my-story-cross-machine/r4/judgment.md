## Exact clarifications accepted

1. Catch inner reviewer StructuredCallFailedError at the review boundary and
   inspect its disposition: schema/parse/check exhaustion is uncertain, never an
   author repair string. An unavailable verifier/prompt_no_room likewise records
   uncertain. Do not unwrap retryable capacity into the outer author ladder.
   Real torch OOM, cancellation and other provider/system failures propagate as
   themselves. Return an error string only for a grounded direct contradiction.
   Record every review attempt separately and persist at existing checkpoints.
2. Adaptive reader splits only on its own measured output_limit or a packet that
   cannot fit. Malformed JSON, schema error or unchanged organization uses bounded
   repair, not automatic subdivision. A one-character irreducible input that
   cannot fit is a genuine envelope/provider failure. Prefer paragraph/newline
   boundaries then a Python character midpoint, two smaller nonempty exact spans.
   Strip-empty optional fields create no SourceDocument; nonempty fields retain
   their exact original whitespace/coordinates. No fixed global packet/depth cap.
3. Standardize optional scheduler capability `_otr_inspect_fit(messages, **kwargs)`.
   Return primitive fits/prompt_tokens/capacity/provenance, with actual native
   preparation and no generation count increment. Put it at the shared scheduler
   factory so bound/unbound callers use the same behavior; do not add wrappers for
   unused unrelated backend helpers. Keep all three existing remote backends,
   including Google, and GGUF routing ahead of native HF side effects.
4. Qualification scope: P0/P1/P3 and final speech require raw-source/candidate
   pair coverage for a whole-source claim; P2 checks the act candidate, against
   its declared raw-source scope. If scope omits raw spans, label it partial;
   never present delivered-only coverage as whole-source qualification. No
   inferred relevance or omitted facts becomes evidence of a checked pair.
5. Cleaner uses typed SpanReplacement(span_id,replacement) entries in a list,
   exact approved-ID set and unique IDs, then original-slice splicing. An empty
   localized replacement may remove a direction but an empty final spoken row
   is not accepted. Do not normalize the protected bytes while validating them.
6. Public abort reuses the existing restored_pre_clean outcome and degradation
   schema, appends reason/evidence, and stores its terminal receipt. Both repeat
   abort and later reconcile return that receipt; no reseal/no-op overwrites.
7. Existing tests must change with their contract: constrained factory metadata
   no longer exposes parser/prefix; by_schema is gone; capacity default accepts
   one available token, while explicit64 and require_full contracts retain refusal.
   Fresh parser/prefix immediately precedes each actual model.generate, including
   min_p retry. This was already explicit in R3, now an executable placement check.
