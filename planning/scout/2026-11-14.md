## Voice / TTS
### Audio8-TTS-Realistic-Air -- TEST
- Link: https://huggingface.co/Edge0/Audio8-TTS-Realistic-Air (card and file list read; files updated 2026-11-13). Successor to the Audio8-Realistic-0.6B already in SEEN as WATCH; what changed is the language list (23, up from 11) and a community int8_convrot bundle.
- What it does: 0.6B DualAR TTS (601M params plus a 44.1 kHz codec), zero-shot cloning from a reference clip plus its exact transcript, or no-reference speech. Would add cloning next to Kokoro.
- Languages: en, es, fr, it, pt, ja, zh (Chinese and Cantonese) and hi are all on the card, so all 8 OTR languages. The card says quality varies by language; its own CV3 test over 9 core languages reports 4.86 percent mean error (by the authors, not us). Not tested by us.
- Speed: no real-time factor published. The authors ran an H20 BF16 smoke test and did not benchmark throughput.
- Weights: Air repo model.safetensors 1.20 GB plus codec.pth 1.35 GB, bf16, ungated, Apache-2.0.
- Sweet-spot build: community, not Comfy-Org: https://huggingface.co/NidAll/audio8-tts-realistic-0.6b-int8-convrot, audio8-realistic-int8-all.safetensors 1.47 GB (TTS plus codec in one file), ungated, Apache-2.0, ConvRot group 64. Caveat: its card says it derives from Edge0/Audio8-TTS-Realistic-0.6b (an earlier revision), not from Air. It loads only through the author's pack https://github.com/NidAll/ComfyUI-Audio8, not a core loader.
- 16 GB fit: estimate only, about 2-3 GB at bf16 (1.2 GB model plus codec); fits 8 GB too. No measured VRAM found.
- ComfyUI requirement: custom pack ComfyUI-Audio8 (third party); not in core. Needs Python transformers 4.57 line (card pins below 5) for the non-ComfyUI route, which may clash with the box torch/transformers stack.
- Risk: 1.2 GB tag of unknown per-language quality in es/fr/it/pt/hi; custom pack and custom remote code; cloning needs an exact reference transcript.
- Probe suggestion: clone one reference voice in each of the 8 languages, listen against Kokoro, time one 10 s line on the 5080.
- Other voice: audio.cpp GGUF collection, Zonos3-Mini, VoxCPM2 already in SEEN (no change). irodori-tts-nodes (pack created 2026-11-14, Japanese TTS, no version data): no verdict. ComfyUI-BytePlus-ModelArk (2026-11-13): CLOUD TTS, SKIP. SFX search found only older items (Stable Audio Open, LTX Foley LoRA, MOSS-SoundEffect v2.0 from May 2026).

## Image
### Kromoss -- TEST (was WATCH on 2026-10-27; material change: official int8_convrot build)
- Link: https://huggingface.co/lodestones/Kromoss (card and file list read; repo updated 2026-11-14). Apache-2.0, ungated.
- What it is: full fine-tune of MOSS-Image-Base at 1024 px, drop-in for the MOSS-Image SFT in Comfy-Org workflows (same text encoder Qwen3.5-9B, same VAE). Challenges the moss_image lane on 16 GB.
- Sweet-spot build: yes, in its own repo: diffusion_models/kromoss_int8_convrot.safetensors 5.41 GB (card says it is the same ConvRot W8A8 format as Comfy-Org's moss_image_sft_int8_convrot). bf16 file is 10.16 GB. Also 8-step DMD and DMD2 LoRAs (1.19 GB each, 8 steps, CFG 1), plus experimental OPD-priming variants.
- 16 GB fit: no measured VRAM; the int8 transformer is 5.4 GB, the text encoder file is 19.3 GB bf16 (needs the existing offload or the int8/smaller encoder the shipped moss_image lane already uses). Estimate only.
- ComfyUI requirement: core already supports MOSS-Image (card says current master; Comfy-Org/MOSS-Image repack has been in tagged builds per earlier reports; tag not re-checked today). Uses standard Load Diffusion Model, Load CLIP type moss_image, Load VAE.
- Risk: the author's training data and any change to faces or style versus SFT is unmeasured by us; MOSS edit LoRAs lose faces (our 2026-10-26 result), so this helps text-to-image only, not character reference.
- Probe suggestion: swap the file in the moss_image still graph, same prompts and seeds, compare period-look stills by eye; try the DMD2 LoRA for 8-step speed.
- Other image: MiniMax-H3-Image repacks, Qwen-Image-2.1 variants, Fibo-2.0 edit templates (workflow_templates 2026-11-14, cloud ship), already covered or off-profile; no verdict.
