## Ming-3.0-TTS (inclusionAI Ming-3.0-tts-tiny, repacked by Comfy-Org)
- Link: https://huggingface.co/Comfy-Org/Ming-3.0-TTS (original: https://huggingface.co/inclusionAI/Ming-3.0-tts-tiny). Repack last updated 2026-10-26.
- What: 7.9B-total / ~1.3B-active MoE speech model. Zero-shot voice cloning from a short clip, voice design from a text description, emotion/speed/pitch/volume control, inline breath/laugh/sigh tags (Chinese/English), multi-speaker dialogue mode. Languages per model card: zh, en, de, es, fr, ko, ja (plus Sichuanese and Cantonese). No it, pt or hi.
- OTR lane: voice. Would challenge or sit beside Kokoro for characters, mainly where cloning or voice design from a description helps cast consistency, and for es/fr/ja/zh episodes.
- 16 GB fit: the Comfy-Org checkpoint is 9.07 GB (measured file size, int8 "convrot"). Runtime VRAM is not published; my estimate is about 10-12 GB with activations, which is tight if shared with other models, so it would need to run in its own phase. 8 GB: unlikely (estimate).
- ComfyUI requirement: Comfy-Org repack (checkpoints/ming3_tts_tiny_int8_convrot.safetensors) suggests native support, but I could not check whether it is in a tagged release or master-only. Must be verified before a probe. The upstream reference code wants Python 3.10, torch 2.7.1 cu118 and an H800, so only the native ComfyUI path is realistic here.
- Weights: ungated, MIT licence, int8 only in the repack.
- Why it matters: voice cloning and voice design, and tagged non-speech sounds, none of which Kokoro offers. Risk: Blackwell/int8 convrot kernel support is unknown; quality on period radio delivery unknown; no it/pt/hi.
- Verdict: TEST (after confirming the ComfyUI tag that carries the loader and node).
