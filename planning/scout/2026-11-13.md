## Voice / TTS

  Link: https://huggingface.co/PatnaikAshish/kokoclone (card and file list read). Kokoro-ONNX plus the Kanade tokenizer as a voice-conversion stage: text in Kokoro, then convert to a 3-10 s reference voice. Card languages: en, hi, pt, es, ja, zh, it (7 of OTR's 8; no fr listed). Main risk: the conversion stage is extra compute and may blur Kokoro's voices; needs an ear test.

## Video
### Kandinsky 6.0 Lite distill, int8_convrot build -- TEST (was WATCH from a news page only)
- What changed: a real ungated int8_convrot build. https://huggingface.co/t8star/Kandinsky-Comfy (card and file list read; created 2026-10-08, MIT): k6_lite_distill_int8_convrot.safetensors 3.77 GB (10 steps, CFG 1), k6_lite_int8_convrot 4.87 GB (50 steps), k6_pro_distill_int8_convrot 34.97 GB (too big for 16 GB).
- What it does: joint video plus 44.1 kHz audio in one pass, I2V/T2V and a reference-portrait workflow; speech comes from prompt tags. Could challenge the LTX 2.5 audio lanes and the H3 ref2va lane for talking-head beats.
- Sweet-spot build: yes, the 3.77 GB file above. Needs separate files: qwen_2.5_vl_7b text encoder 16.58 GB (an fp8 version of 9.38 GB is reported by a third-party guide, not read by me), clip_l 0.25 GB, Hunyuan video VAE 0.49 GB, audio VAE 1.22 GB, BigVGAN 0.49 GB.
- 16 GB fit: no measured peak VRAM found. Guide says 12-24 GB for Lite (estimate, unmeasured). The 16.58 GB text encoder must be offloaded or fp8. 8 GB: unlikely.
- ComfyUI requirement: not in tagged core as far as I found; needs the Kandinsky T8 pack (https://github.com/T8mars/Comfyui-Kandinsky-T8, 0.1.4+, comfy-kitchen 0.2.37+, an NVIDIA GPU with INT8 tensor cores) or the registry node "kandinsky6". The Blackwell INT8 path was not checked by me.
- Languages for speech: not stated on the pages I read. Check before use.
- Main risk: separate large text encoder, third-party pack, speech language coverage unknown, no lip-sync quality evidence from us.
- Other video: Pika-H3-Flex, HyperFlow, Vimoo, PAN2 already in SEEN. New small LoRAs (Frieren H3 LoRA, lucidml/gta) are style or game items: no verdict.

## Upscalers
- PiD, NVIDIA Pixel Diffusion Decoder (https://huggingface.co/nvidia/PiD; created 2026-04-28, v1.5 in July; card and file list read) -- WATCH. Replaces a model's VAE decode with a 4-step pixel-space diffusion that draws 4x width and height (512 -> 2048 px, up to 4K). Checkpoints for FLUX.2, FLUX, Qwen-Image, SD3, SDXL, as bf16 .pth. Community ComfyUI workflows turn it into a general 4x upscaler by encoding any image with the FLUX.2 VAE (https://huggingface.co/lvladikov/PiD-as-pixel-Upscaler, card read; authors' claims). Sweet-spot build: none (bf16 .pth). Licence NSCLv1, non-commercial (reported, not a gate). Core: not verified; the community path uses workflows, loading route not confirmed. Whether it fits next to flux3_klein's VAE is not verified. Main risk: it invents detail, so faces can drift between beats; VRAM unmeasured.
- MiniMax H3 latent upscalers (George0667 v2 659 MB bf16/fp16 with 8/12/16 -> 24 fps temporal variant, chenzs 3D BF16) -- SKIP: H3 only, no effect on LTX lanes. Not logged individually beyond this line.

## Writer LLMs (experimental)
### noirwrit-base (tejgokani) -- TEST
- https://huggingface.co/tejgokani/noirwrit-base (card read; created 2026-10-29; not in SEEN). Base: none, a from-scratch Llama-layout decoder, 97.5M parameters, 2048 context, own 16k BPE. Formats: GGUF q8_0 (112 MB), q4_k_m (66 MB), fp16 PyTorch .pt (210 MB). 16 GB fit: trivially (estimate; runs on CPU through llama.cpp). Licence MIT. Corpus: 1,828 public-domain crime, detective and pulp books from Project Gutenberg, all published 1930 or earlier; 719M training tokens; trained on one free T4 (author numbers).
- Sample sentence from the card (a prompt, not output): "They found the body at the foot of the stairs, and by the time I got there the rain had".
- Run via llama.cpp (llama-completion, base model, give it a passage start) or the author's Noirwrit app. Experiment: feed it the opening of a noir beat as a period-voice generator for narrator or detective lines, compared with the shipped writer's prompted noir. Risk: 97M is tiny, so expect weak coherence; it is a flavour sampler, not a script writer. This is the operator's own experiment, not a quality chase.
### Bart (jbduran/bartholomew, 2.8B) -- WATCH
- https://huggingface.co/jbduran/bartholomew (card read; base created 2026-06-05, SFT 2026-08-21; not in SEEN). 2.82B parameters trained from scratch on 20.1B tokens of pre-1930 public-domain books, nanochat format, fp8-tensorwise training, final weights model_009600.pt 8.99 GB (PyTorch .pt, no safetensors or GGUF seen). MIT. Write-up: https://www.unboundedlab.com/blog/bartholomew. 16 GB fit: estimate yes in bf16 (about 5.6 GB), but it needs the nanochat code, no transformers or llama.cpp path found. Instruction-tuned sibling: jbduran/bartholomew-sft (file list read, card not read). Risk: loader work. Compare talkie-1930 (13B, already TEST in SEEN).
