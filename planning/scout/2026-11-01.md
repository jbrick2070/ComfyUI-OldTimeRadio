## Voice / TTS
### MOSS-TTS family + ComfyUI-MOSS-TTS pack -- WATCH (new to SEEN)
- Pack: https://github.com/marduk191/ComfyUI-MOSS-TTS (registry id comfyui-moss-tts 1.1.0, published 2026-10-31; README not read, registry summary only). Models: https://github.com/OpenMOSS/MOSS-TTS (README read this run); models themselves date from Feb to Jul 2026.
- What: MOSS-TTS-v1.5 (8B) and Local-Transformer-v1.5 (4B, 1.7B older) cover 31 languages; per the README, all eight OTR languages (en, es, fr, it, pt, ja, zh, hi) are included. Zero-shot cloning, continuation, voice design (MOSS-VoiceGenerator 1.7B), dialogue (TTSD 8B). Challenges Kokoro on cloning; Nano (~0.1B) is stated to run in real time on 4 CPU cores.
- Sweet-spot build: none for ComfyUI. Community int8 exist only as ONNX or MLX (REALBITS/MOSS-TTS-Nano-100M-ONNX-int8, shraey/...-MLX-int8, not inspected). Official Q4_K_M GGUF is gated (auto).
- Fit: README says the 8B fits 8 GB through the llama.cpp path (author claim). No RTF for 8B or 4B; only MOSS-TTS-Realtime 1.7B RTF 0.51 on an L20 (author, measured). 
- ComfyUI: custom node pack; downloads weights on first use (against OTR's pinned-revision rule).
- Risk: speed of the 8B/4B on the 5080 unknown; auto-download. Verdict WATCH: probe the Nano and 1.7B Local first if the operator wants a cloning experiment.

## Image
### MOSS-Image-IDM-2-Steps (akhaliq) -- WATCH (new to SEEN)
- https://huggingface.co/akhaliq/MOSS-Image-IDM-2-Steps (card read; updated 2026-11-01, Apache-2.0).
- What: a LoRA that runs MOSS-Image-SFT in 2 steps without CFG (100 forwards down to 2). Author reports 2 of 8 dense-text prompts beat the 50-step teacher (author eval). The v2 edit variant is experimental and the card says it regressed T2I.
- Sweet-spot: none (LoRA on the MOSS-Image base; Comfy-Org/MOSS-Image repack exists). Native support: LoRA path via standard loader is likely but the card does not say; unverified.
- Relation to OTR: moss_image stills on 16 GB graphs; speed only. Quality parity at 2 steps unproven for OTR's style. Verdict WATCH.
