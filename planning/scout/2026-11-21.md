## Voice / TTS
### Reverb-TTS (software-mansion, card read; node pack posted 2026-11-21) -- TEST
- Link: https://huggingface.co/software-mansion/Reverb-TTS ; node pack https://github.com/Wolfricbr/ComfyUI-Reverb-TTS (registry id comfyui-reverb-tts 0.3.9, depends on reverb-tts==1.0.0).
- What it does: zero-shot voice cloning from a 3-20 s reference plus its transcript; 16 preset voices; no style control beyond the reference. A pruned and distilled OmniVoice (297M per the header, 319M in the table) retrained on seven languages with DPO post-training. Adds cloning, which Kokoro lacks.
- OTR languages: en, es, fr, it, pt covered (5 of 8). de and pl are extra. ja, zh, hi are NOT covered.
- Sweet-spot build: int8 safetensors 307 MB (model/safetensors/int8/model.safetensors), default variant; int8a8 307 MB; int4 191 MB; fp16 594 MB; ungated. Not the Comfy-Org int8_convrot naming. Card says int8 showed no quality loss vs fp32 on their internal set (their claim, not measured here).
- 16 GB / 8 GB fit: weights under 1.2 GB at any precision; 8 GB fit is near certain (estimate).
- Speed (published by the authors, bf16 PyTorch, not measured by us): 164.9x real time on RTX 5090 at batch 32; 12.3x on Apple M4 Pro at batch 1 (the OmniVoice base is 0.84x on the same Mac). No batch-1 CUDA number. Also ExecuTorch builds (MLX, Vulkan, QNN, XNNPACK).
- ComfyUI: no core support; custom pack above. Risk: the pack is brand new, 0 downloads, and the registry status reads Flagged; licence file unnamed. Run it from the pip package first.
- Licence: CC-BY-NC-4.0 (reported only, not a gate). Needs text normalisation (Verbalis, bundled by the pip package).
- Why it matters: first small, fast cloning model that covers 5 of 8 OTR languages; this supersedes the 11-20 OmniVoice WATCH (same family, about half the size, 10-20x faster per the authors). Main risk: no ja/zh/hi, and the voices copy room noise of the reference.
- Probe idea: clone two reference voices, render one scene in en and one in es, compare against Kokoro by ear and time batch 1 on the 5080.
- Verdict: TEST.

## Upscalers
### Steppe latent upscaler (TensorForger/ComfyUI-Steppe, registry 2026-11-21) -- WATCH
- Link: https://github.com/TensorForger/ComfyUI-Steppe ; https://api.comfy.org/nodes/steppe (registry description read; the GitHub README was not read).
- What it does: 2x resolution and 2x frame rate in latent space for Wan 2.1, Wan 2.2 14B and Qwen-Image latents, decoded by the VAE with no extra sampling pass. Needs a node pack, not UpscaleModelLoader.
- OTR relevance: none of the shipped lanes use Wan or Qwen-Image latents (LTX 2.5, H3, Klein, MOSS), so no direct fit; interesting only as a pattern for the 8 GB lanes. No weights, int8 or fit data read.
- Verdict: WATCH at most (registry page only).

Nothing else new.
