## Voice / TTS
### KittenTTS 2 Mini (KittenML, updated 2026-11-18) -- TEST (update of the 2026-10-27 KittenTTS 2 row)
- Link: https://huggingface.co/KittenML/kitten-tts-2-mini (card and file list read).
- What changed: a Mini variant with 16 languages (en, de, es, it, pt, ru, hi, da, fi, fr, ja, ko, nl, sv, sw, tr), 118 voices, 24 kHz, 82M parameters. OTR languages covered: en, es, fr, it, pt, ja, hi (7 of 8); zh is missing. Non-English voices are mostly generic ("Female 1", "Male 2"); English voices have character descriptions (for example "Weathered radio journalist").
- Sweet-spot build: not a ComfyUI diffusion model, so int8_convrot does not apply; it ships ONNX int8 (kitten_tts_2_mini.onnx, 82.7 MB) and int4 (47.5 MB), plus float32 safetensors 327 MB.
- 16 GB fit: runs on CPU, zero VRAM (card says no PyTorch needed). Speed: no real-time factor in the part of the card read.
- ComfyUI: no core support, no registry pack seen. Needs the `kittenml` pip package (a small wrapper node would be needed).
- Licence: apache-2.0. No cloning.
- Why/risk: same shape as Kokoro (CPU, no cloning) with more languages and described English characters; risk is quality versus Kokoro, which only a listening test settles.
- Verdict: TEST (CPU probe, A/B by ear against Kokoro on the same lines).
