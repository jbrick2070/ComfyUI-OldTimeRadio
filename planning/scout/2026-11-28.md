## Voice / TTS
**Libra-TTS (Ekam) -- WATCH.** Link: https://huggingface.co/Ekam/Libra-TTS (files updated 2026-11-28; first seen in the hub list 2026-11-26).
- What: multilingual TTS, 307M talker + 114M Qwen3-TTS codec decoder, distilled from a fine-tuned Qwen3-TTS-1.7B. 8 named voices, 12 speaking styles, language auto-detected per sentence. Languages on the card: en zh ja ko de fr es it pt ru ar hi pa bn ur id -- all 8 OTR languages (en, es, fr, it, pt, ja, zh, hi). Would challenge Kokoro as a speech engine; it has NO cloning, same as Kokoro.
- Card numbers (author's own, not measured by us): English WER 1.64% vs Kokoro-82M 1.80% on the author's seed-tts-eval run; 10-language average 1.77%. Speed (author, measured): 8.7x real time on an RTX 3090 for one sentence at a time (2.4 GB GPU memory), 72x on long text; 7.7x on a MacBook Pro M5 Max (MLX, 2.0 GB); 2.4x on a Mac CPU via ONNX. For comparison Kokoro on OTR is about 0.19x real time on CPU (RTF), so 2.4x real time on CPU would be faster than that -- but the two numbers come from different hardware and methods.
- Sweet-spot build: none in the ComfyUI sense. Official files: model.safetensors bf16 614 MB, codec.safetensors 373 MB, ONNX fp32 1.74 GB. Third-party CPU build https://huggingface.co/Hansda/Libra-TTS-INT8-ONNX (ungated, Apache-2.0, 759.5 MB total, dynamic int8 MatMuls; the card says it produced non-silent English and Spanish audio, no quality numbers). That is ONNX Runtime int8, not a ComfyUI core loader format.
- 16 GB / 8 GB fit: published 2.4 GB GPU memory on a 3090 (author, measured). Fits both boxes easily.
- ComfyUI requirement: none found. The registry API (term tts, window 11-25 onward) shows no Libra node; a web search found none. It runs through its own `libra-tts` Python package (MLX / CUDA / ONNX), so OTR would need a small wrapper node or a direct call.
- Weights: ungated, Apache-2.0, bf16 + fp32 ONNX.
- Risks: day-old release, 933 downloads, single author, no cloning, no ComfyUI path, package installs from a GitHub zip (not a pinned release). Quality claims are the author's own.
- Experiment if the operator wants one: run the 8 voices on the 8 OTR languages and compare by ear against Kokoro for non-English lines.
- Verdict: WATCH (primary source read: model card and file listing). Would become TEST if a ComfyUI node or an int8 safetensors repack appears.
