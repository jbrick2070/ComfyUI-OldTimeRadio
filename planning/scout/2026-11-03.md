## Voice / TTS
### Silencio-2 (BlueRoseLabs) -- WATCH
- https://huggingface.co/BlueRoseLabs/Silencio-2 (card read; updated 2026-11-01).
- What: fine-tune of Kyutai Pocket TTS (18M) that follows inline tags: [laugh] [sigh] [gasp] [cough] [clear_throat] and <happy> <sad> <angry> <fear> <surprised> <whisper>; clones a voice from a short clip; streams. Author figure (not independently measured): about 20x real time on 4 CPU threads of an Apple M4. Single file model.safetensors 111.75 MB; optional int8 on CPU via its own package (not ComfyUI int8).
- Languages: English only (0 of OTR's other 7). CC-BY-4.0, ungated. Own inference package `silencio2`; no ComfyUI node or core support found.
- Sweet-spot build: none (not applicable at this size; CPU int8 option is in its own package).
- 16 GB fit: trivially small (112 MB); CPU is fine. Would challenge Kokoro only for English cloning and in-line non-verbal sounds (sighs, gasps), which Kokoro lacks.
- Risk: English only, tiny model so voice quality unknown; no loader in ComfyUI. Verdict WATCH: a by-ear probe of the [sigh]/[gasp] tags in a standalone script is cheap if the operator wants it.
