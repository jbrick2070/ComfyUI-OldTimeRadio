## Upscalers
**Kandinsky ImageSR 2.0 (kandinskylab, 2026-11-25) -- WATCH.** https://huggingface.co/kandinskylab/Kandinsky-ImageSR-2.0
- What: diffusion image super-resolution, one transformer for x2 and x4, one-step sampling, 1024 px output tiles with blended overlaps (card read). Would sit beside ESRGAN-family upscalers for stills; it is image only, not video.
- Sweet-spot build: none yet. Weights are bf16 diffusers shards: transformer 10.25 GB in three files plus a 168 MB VAE (measured from listing). It would need int8 or int8_convrot; Comfy-Org (which has repacked other Kandinsky pieces and RelayVSR) is the plausible maker.
- 16 GB fit: no published figure except speed on an H100 (measured by the authors): 2.78 s for 1K to 2K, 7.8 s for 1K to 4K, 37.5 s for 2K to 8K. VRAM not stated. 10 GB bf16 weights should fit 16 GB with tiling (estimate), 8 GB unlikely.
- ComfyUI: no core support seen (the pipeline needs the kandinsky_image_sr package and diffusers 0.41+); not loadable through UpscaleModelLoader/spandrel. Would need a node pack or a core model class. No node pack found this run (registry API not queried for this name).
- Licence MIT (VAE Apache-2.0), ungated. Risk: generative upscaling can alter faces; same character-consistency caution as above.
- What shipped to verify: apple/VIDEO_MODELS.md line 112 confirms the 8 GB LTX 2.5 lanes drop the refine pass (832x480); nothing new here reaches video.
