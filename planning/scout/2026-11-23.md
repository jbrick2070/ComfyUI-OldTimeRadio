## Voice / TTS
**BlueV3 (notmax123, v3.0.1, updated 2026-11-23) -- WATCH**
- Link: https://huggingface.co/notmax123/BlueV3 ; ONNX bundle https://huggingface.co/notmax123/BlueV3-onnx ; code https://github.com/maxmelichov/BlueTTS
- What: zero-shot cloning TTS, flow matching, 44.1 kHz, 8 Euler steps. Trained on 7 languages: Hebrew, English, German, Spanish, Italian, Russian, Yiddish. OTR overlap: en, es, it (3 of 8; fr, pt, ja, zh, hi are missing). Would challenge Kokoro only for English/Spanish/Italian with cloning.
- Card scores (author, measured on their own test set): English WER 1.88%, English speaker similarity 0.671; Spanish speaker similarity 0.454 and Italian 0.432 (the card notes cross-language voices score lower). No real-time factor is published.
- Sweet-spot build: none in the core int8 / int8_convrot format. The ONNX bundle has vector_estimator.int8.onnx at 66 MB (fp32 257 MB) plus decoder/vocoder about 101 MB each, reference encoder 136 MB. Runs outside ComfyUI core loaders.
- ComfyUI: no node pack found; needs its own runtime (PyTorch or ONNX) and a G2P frontend per language.
- Weights: PyTorch plus separate blue-codec repo; ungated. Licence: MIT, codec decoder is an OpenRAIL-M derivative (reported only).
- 16 GB fit: well under 1 GB of weights (estimate from file sizes), should run on CPU or GPU.
- Risk: only 3 of 8 OTR languages, no pack, cloning is similarity-limited on non-English per its own card. Verdict WATCH: wait for a pack or a speed number.
Also seen and rejected: n4ze3m/tiny-voca (4.5M, English only, two fixed voices, no cloning, Apache-2.0), higurashi-ai/Haru-4B (full-duplex spoken dialogue model, not a narration TTS; about 12 GB), audio-cpp/audio.cpp-gguf (collection of GGUF audio runtimes, already in SEEN).

## Image
**H3 Image Character Swap LoRA V1 (akatz-ai, 2026-11-20; Comfy-Org template added 2026-11-23) -- WATCH**
- Links: https://huggingface.co/akatz-ai/MiniMax-H3-Image-Character-Swap-LoRA ; template image_minimax_h3_image_character_swap in Comfy-Org/workflow_templates (commit da38c7a).
- What: replaces a person in a still with a character from a reference sheet, carrying face, costume and style while following source pose and lighting. Challenges: flux3_klein_ref (identity-consistent stills). Core nodes only (UNETLoader, CLIPLoader, LoadLoraModel, MiniMaxH3ImageConditioning, KSampler); the author tested ComfyUI 0.45.0 on an RTX 4090.
- Sweet-spot build: base is Comfy-Org/MiniMax-H3-Image minimax_h3_image_pruned_int8_convrot.safetensors, 20.98 GB (https://huggingface.co/Comfy-Org/MiniMax-H3-Image), ungated. The LoRA itself is 155 MB bf16. Other base precisions in that repo: bf16 40.2 GB, w4a8 12.5 GB. Text encoders: qwen3vl_32b int8_convrot 27.1 GB, nvfp4 awq 15.7 GB, qwen3.5_9b w4a8 gptq 7.3 GB.
- 16 GB fit: the int8 base (21 GB) plus encoder does not fit 16 GB without offload; the w4a8 base (12.5 GB) plus the 7.3 GB 9B encoder is the only combination near the 16 GB ceiling (my estimate from file sizes, not measured, and whether the LoRA works on w4a8 is untested). Not an 8 GB option.
- ComfyUI: core release v0.45.0 or newer (the H3 Image support is in SEEN as core v0.45.0).
- Licence: MiniMax H3 Image community licence (reported only).
- Why it might matter: a second route for character-consistent stills, built for swapping into an existing frame rather than painting from a portrait. Risk: base size; the OTR 2026-10-26 measurement that MOSS-Image edit loses the face is a different model and says nothing about this one. Verdict WATCH: only a probe if a smaller H3 Image quant or a 16 GB recipe appears.
Also seen: Comfy-Org/UltraTex (Flux Klein 9B PBR texturing for 3D models, not stills: SKIP), RMBG 3.0 template (background removal: SKIP), tuanlai001/H3-IMAGE-PE-HERETIC-NVFP4-COMFYUI (personal repack, card not read).
