## Voice / TTS
### OmniVoice (k2-fsa, card dated by 2604.00688 paper, 4.3M downloads) -- WATCH
- Link: https://huggingface.co/k2-fsa/OmniVoice (card and file list read).
- What it does: diffusion-language-model TTS, zero-shot voice cloning from a reference clip plus its transcript, voice design, non-verbal symbols. Output 24 kHz. Base Qwen/Qwen3-0.6B.
- OTR languages: card language list includes en, es, fr, hi, it, ja, pt; zh was not visible in the part of the list read (truncated), so 7 of 8 confirmed at most.
- Sweet-spot build: none. Files: model.safetensors 2.45 GB plus audio_tokenizer 0.81 GB; int8 / int8_convrot not offered. Who would make it: Comfy-Org or a community packer, only if ComfyUI gains a core class.
- 16 GB fit: estimate under 4 GB at fp16 (0.6B model plus tokenizer), not measured. 8 GB fit likely. No real-time factor in the card.
- ComfyUI: no core support seen; pip package `omnivoice` (card), so a custom node would be needed.
- Licence: code Apache-2.0, weights CC-BY-NC (reported only; not a gate).
- Why/risk: cloning in all but possibly one OTR language at small size is the gap Kokoro leaves; risk is speed and quality at the edge languages, which only a listening test settles.
- Verdict: WATCH (no ComfyUI path yet, no speed number). Would become TEST if a ComfyUI node or an RTF number appears.

## Writer LLMs (experimental)
### TimeCapsuleLLM English 1800-1875 v3-mini-eval, 500M (haykgrigorian; GGUF by longchps) -- WATCH
- Link: https://huggingface.co/haykgrigorian/TimeCapsuleLLM-English-1800-1875-v3mini-eval1-500M (card read); GGUF https://huggingface.co/longchps/TimeCapsuleLLM-English-1800-1875-v3mini-eval1-500M-GGUF (Q4_K_M 327 MB, Q8_0 531 MB).
- Base: none, trained from scratch (Llama architecture, 24 layers, GQA, 4096 context). About 500M parameters. Formats: safetensors (transformers, `final/` subfolder) and community GGUF.
- Corpus: about 5.7B tokens sampled from 1800-1875 English texts (newspaper, sermon, diary, parliamentary, scientific), cutoff 1875. Card notes OCR residue, topic drift over long text, no date leakage found (author's evaluation, not mine).
- 16 GB fit: far under (about 1 GB at bf16, estimate). Licence Apache-2.0.
- Sample sentence: the card shows none.
- Experiment: a larger-than-before 1800-1875 period base than the 1.2B v2 already listed in SEEN is not what this is (it is smaller, a later eval build), so use it as a fast period-voice probe for a continuation-style drafting pass or a text-completion test of Victorian narration; it is a base model with no instruction tuning shown, so it cannot take OTR's script prompts as they are.
- Verdict: WATCH.
